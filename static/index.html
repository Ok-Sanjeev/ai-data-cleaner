    import requests

BASE = "http://localhost:8000"
# 1. Profile
res = requests.post(f"{BASE}/api/profile", json={"filepath": "data/dirty.csv"}).json()
session_id = res["session_id"]

# 2. Plan
plan = requests.post(f"{BASE}/api/plan", json={"session_id": session_id, "provider": "gemini"}).json()

# 3. Clean
clean = requests.post(f"{BASE}/api/clean", json={
    "session_id": session_id,
    "approved_action_ids": list(range(len(plan["actions"])))
}).json()
print("Cleaned cells:", clean["diff_summary"]["modified_cells_count"])

    Zero Raw-Data Leakage Architecture

    Enterprise data cleanliness shouldn't require surrendering privacy. AI Data Cleaner isolates raw records from all external LLM network calls:

    What LLM Providers Receive:

    Abstract statistical metadata: Column names, inferred semantic types, missing value percentages, and heuristic error flags.

    What Is NEVER Transmitted:

    No actual row cell values, no PII (emails, names, phone numbers), no proprietary financial metrics, and no customer identifiers.

    Transformations are synthesized as abstract deterministic recipes, which are locally validated through guardrails and executed on your local machine using Pandas.
