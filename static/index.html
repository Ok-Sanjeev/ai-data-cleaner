Workflow

How It Works

A transparent engineering workflow combining interactive exploration with human verification and deterministic execution.

01

Upload & Profile

Upload any CSV. DataRefine analyzes column schemas, type inference, missing value patterns, anomalies, and duplicates without sending raw rows off-premises.

02

Explore & Cluster

Slice multi-column facets, inspect value distributions, detect text misspellings with fingerprint clustering, and test expressions in real-time.

03

Review & Approve

Inspect explainable AI recommendations categorized into GREEN (Safe Repair), YELLOW (Needs Review), and RED (Destructive). You retain 100% control.

04

Execute & Export

Clean with Python determinism, verify changes via the Side-by-Side Visual Diff, and export cleaned CSVs, audit JSON, or Benchmark Evaluation reports.

Core Architecture

Enterprise Data Quality Guarantees

Engineered to eliminate manual data-wrangling tedium while guaranteeing privacy, auditability, and absolute determinism.

🛡️ Zero Raw Data to External AI

A centralized outbound payload privacy gate strictly blocks CSV rows, personal records, and raw cell values. Gemini receives only allowlisted statistical summaries.

⚙️ 52 Predefined Deterministic Actions

Transformations execute using tested Pandas and Python routines. No arbitrary code, hallucinated scripts, or black-box mutations run against your dataset.

🧩 DataRefine Clustering Studio

Standard fingerprinting, n-gram collisions, phonetic Soundex/Metaphone, and Levenshtein distance metrics identify inconsistent categories automatically.

🚦 3-Tier Safety Guardrails

GREEN (Safe Repair) pre-checked, YELLOW (Needs Review) highlighted for inspection, and RED (Potentially Destructive) unchecked by default.

⚡ AST-Sandboxed Expression Engine

Express complex string, regex, date, and math transformations safely. Syntax trees are restricted to safe AST nodes, preventing unauthorized code execution.

🔍 Side-by-Side Visual Diff & Benchmark Evaluation

Inspect exactly what changed cell by cell with color-coded diff highlights. Run automated Benchmark Evaluation against ground truth to verify precision and recall.

↺ Audit History & Rollback

Every operation records an immutable snapshot. Undo steps, redo operations, or jump back to any previous state with full data integrity.

🚀 Zero-Action Clean Dataset Workflow

If your dataset already satisfies quality criteria, DataRefine displays a clean verification status and allows direct export without forced modifications.

🧪 170 Automated Unit & API Tests

Rigorous test-driven engineering covering clustering algorithms, AST security, facet calculations, entity reconciliation, AI privacy gates, and endpoints.

Zero Data Leakage Architecture

Enterprise Privacy & Deterministic Safety

DataRefine is architected from the ground up so sensitive customer records, financial rows, and identifiers never leave your network boundary.

✓ Transmitted to AI (Sanitized Metadata Only)

Column names, inferred data types, aggregate missingness percentages, anomaly category flags, and row counts. Validated strictly by validate_outbound_payload() before any network egress.

🛡️ Kept Strictly Local (Never Sent to AI)

Raw CSV files, cell values, row samples, customer names, emails, addresses, financial figures, and unique IDs. Transformations execute locally via deterministic Python routines.

Deterministic Actions: No hallucinated scripts or arbitrary code execution.
AST Sandboxing: Expressions evaluated via restricted AST node whitelists.
Total Auditability: Step-by-step undo, redo, and point-in-time state rollback.
