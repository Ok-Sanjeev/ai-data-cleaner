Workflow

How It Works

A transparent three-step engineering workflow built around human verification.

01

Upload & Profile

Drag and drop your CSV dataset. DataRefine automatically profiles column structures, data types, missing value distributions, duplicates, and statistical anomalies without sending raw records.

02

Review & Clean

Inspect AI-generated recommendations categorized into GREEN (Safe Repair), YELLOW (Needs Review), and RED (Potentially Destructive). Approve individual operations before applying changes.

03

Results & Export

Compare changes with the Side-by-Side Visual Diff, test rollback checkpoints, and download cleaned CSVs, JSON audit reports, or Benchmark Evaluation metrics.

Core Architecture

Key Features

DataRefine provides a robust, transparent AI Data Cleaner designed to eliminate manual data-cleaning tedium without black-box code execution.

AI-Powered Cleaning Recommendations

High-accuracy recommendations generated from privacy-safe statistical profiles, governed by strict column contracts.

Deterministic Data Processing

Transformations execute using tested Pandas and Python routines. No arbitrary, unreviewed code or hallucinated scripts run against your dataset.

Privacy-Aware AI Planning

Raw cell values and category labels are withheld from LLM prompts. Only structural metadata and schema shapes are analyzed.

Automated Dataset Profiling

Instant detection of missing rates, encoding issues, delimiters, numerical statistics, IQR outliers, and semantic hints.

Human-in-the-Loop Approval

3-tier risk system: GREEN (Safe Repair) pre-selected, YELLOW (Needs Review) highlighted, and RED (Potentially Destructive) unchecked by default.

Side-by-Side Visual Diff

Inspect exactly what changed cell by cell. Highlight modified values in green with pre-cleaned hover tooltips and delta summaries.

Audit History & Rollback

Every operation records an in-memory checkpoint. Undo steps, redo operations, or jump back to any previous state with full data integrity.

Data Quality Validation

Automated post-cleaning checks verify that row counts, dtypes, and null reduction meet expected criteria before checkpoint approval.

Benchmark Evaluation & Export

Download cleaned datasets in standard CSV format, retrieve comprehensive JSON audit reports, or run Benchmark Evaluation against ground truth.

Security Architecture

Accurate, verifiable privacy & safety

DataRefine is architected specifically to keep confidential data in your environment.

What is transmitted to AI:

Only statistical schema metadata: Column headers, inferred data types, missing value percentages, and heuristic anomaly flags.

What remains strictly local:

All raw cell records, personal identifiers, customer entries, and financial data. Transformations execute locally via verified Python and Pandas routines.

Predefined Operations: No arbitrary code or dynamic SQL queries.
Strict Validation: Pydantic type checks and Python local guardrails.
Full Auditability: Step-by-step undo, redo, and state rollback.
